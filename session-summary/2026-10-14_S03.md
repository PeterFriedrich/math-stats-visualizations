## 3. Technical Learnings
- **The repo rename broke the old Pages URL:** GitHub redirects the repo but not Pages. The new URL is https://peterfriedrich.github.io/math-stats-visualizations/.
- **The owner merges PRs within minutes.** PR #5 merged before my follow-up push, and `.githooks/pre-push` blocked the push to the dead branch. I cherry-picked onto a new branch (#6). Check `gh pr view <n> --json state` before every push, and don't chain the check with `&&`, because `gh` prints MERGED and exits 0.
- **I skipped the latest session summary and `TODO.md` at the start**, and the owner caught it. They held an open TODO item that the rename closed. Read them first, even for a small peer request.
- **The two quadratic entry points take different inputs.** `completeSquare(a, b, c)` and `xIntercepts` take whole numbers, while `linearProduct` takes `[n, d]` rationals. Slider values with 0.5 steps go through `fromSlider` (`r(Math.round(v * 2), 2)`) in the sim.
- **Number display in `linear-product.js`:** `places(f)` returns the decimal places needed to terminate, or −1. `num()` gives a decimal or a fraction, and `qty()` adds a unit and "≈". `chain()` joins `a = b = c` but writes "≈" in place of "=" before a rounded value, and `about()` turns "≈ " into "about " in prose.
- **Screenshots of a sim at a given step:** `tools/verify-sims.js` only shoots the first step. I used a scratchpad Playwright script that selects the scenario, sets the last slider, clicks "Show all" and prints `.steps-list` text. That script is gone with the scratchpad, but rewriting it is about 30 lines using `createServer` from `tools/serve.js`.
- PIL is not installed for `python3.12` here.
- Server quirks are unchanged: run the guards with `python3.12`, and prefix Playwright with `NODE_PATH=/home/opc/edmonton-tax-viz/tools/profiling/node_modules`. Headless Chromium uses a monospace-looking fallback font.
